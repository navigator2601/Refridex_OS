# Проєкт Refridex OS

## Опис проєкту

Це Telegram-бот, розроблений на базі `aiogram` та `asyncpg` з інтеграцією `Telethon` для роботи з Telegram API.
Основна функціональність полягає в автоматизації обліку монтажних робіт, навігації по торгових точках (ТТ), введенні та розрахунку замірів магістралей, парсингу вхідних заявок та диспетчеризації підсумкових звітів у робочі групи.
