# Проєкт Refridex OS

## Опис проєкту

Це Telegram-бот, розроблений на базі `aiogram` та `asyncpg` з можливістю розширення через `Telethon` для роботи з Telegram API.
Основна функціональність полягає у наданні інформації про кондиціонери та кліматичну техніку, зручній навігації по каталогу товарів, пошуку та взаємодії з користувачами через панель керування.
